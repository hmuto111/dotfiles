# Neovim チートシート

## モード切り替え

| キー | 動作 |
|:---|:---|
| `Esc` / `Ctrl + [` | ノーマルモードに戻る |
| `i` | カーソルの手前から入力（insert） |
| `a` | カーソルの後ろから入力（append） |
| `o` | 下に新しい行を作って入力 |
| `O` | 上に新しい行を作って入力 |
| `A` | 行末に移動して入力 |
| `v` | ビジュアルモード（範囲選択） |
| `Ctrl + v` | 矩形ビジュアルモード（列選択） |
| `:` | コマンドモード |

## カーソル移動

| キー | 動作 |
|:---|:---|
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 |
| `w` | 次の単語の先頭へ |
| `b` | 前の単語の先頭へ |
| `0` | 行頭へ |
| `$` | 行末へ |
| `gg` | ファイルの先頭へ |
| `G` | ファイルの末尾へ |
| `<数字>G` | 指定行へジャンプ（例: `15G`） |

## 編集（動詞 + 範囲）

### 基本の動詞
- `d` = 削除（切り取り）
- `y` = ヤンク（コピー）
- `c` = 削除してインサートモードへ

### よく使う組み合わせ

| キー | 動作 |
|:---|:---|
| `dd` | 1行削除 |
| `yy` | 1行コピー |
| `cc` | 1行削除してインサートモードへ |
| `dw` | 単語1つ削除 |
| `yw` | 単語1つコピー |
| `d$` / `D` | カーソルから行末まで削除 |
| `y$` / `Y` | カーソルから行末までコピー |
| `p` | カーソルの後ろに貼り付け |
| `P` | カーソルの手前に貼り付け |
| `u` | 元に戻す（Undo） |
| `Ctrl + r` | やり直す（Redo） |
| `3dd` | 3行削除 |
| `3yy` | 3行コピー |

### テキストオブジェクト（括弧・引用符の中身を操作）

| キー | 動作 |
|:---|:---|
| `ci"` | `"..."` の中身を消して入力 |
| `di"` | `"..."` の中身を削除 |
| `yi"` | `"..."` の中身をコピー |
| `da"` | `"..."` を引用符ごと削除 |
| `ci(` | `(...)` の中身を消して入力 |
| `di{` | `{...}` の中身を削除 |
| `yi{` | `{...}` の中身をコピー |
| `yit` | HTMLタグの中身をコピー |

### ヤンク応用

| キー | 動作 |
|:---|:---|
| `y0` | カーソルから行頭までコピー |
| `yG` | カーソルからファイル末尾まで全部コピー |
| `ygg` | カーソルからファイル先頭まで全部コピー |
| `y/検索語` | カーソルから検索語の位置までコピー |
| `"+yy` | OSのクリップボードへ1行コピー |
| `"+yi"` | OSのクリップボードへ引用符の中身をコピー |

## ファイル操作（コマンドモード）

| コマンド | 動作 |
|:---|:---|
| `:w` | 保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 保存せず強制終了 |

## AstroNvim 独自キーバインド

### タブ（バッファ）移動

| キー | 動作 |
|:---|:---|
| `]b` | 右のタブへ |
| `[b` | 左のタブへ |
| `Space + 1` 〜 `Space + 9` | 左から数えて指定番号のタブへ移動 |
| `Space + b + d` | タブを選んで閉じる |

### ファイル検索・操作

| キー | 動作 |
|:---|:---|
| `Space + e` | ファイルツリーの開閉 |
| `Space + f + f` | ファイル名で検索 |
| `Space + f + w` | ファイル内の文字列で全体検索（要 ripgrep） |
| `Space + f + b` | 開いているバッファから検索 |

### ウィンドウ（画面分割）操作

| キー | 動作 |
|:---|:---|
| `Ctrl + h / j / k / l` | ウィンドウ間移動（smart-splits） |

### その他

| キー | 動作 |
|:---|:---|
| `Space` を押して待つ | WhichKey メニュー表示（使えるキーの一覧） |

## 設定ファイルの場所

| ファイル | 役割 |
|:---|:---|
| `lua/plugins/astrocore.lua` | 基本オプション・キーバインド設定 |
| `lua/plugins/smart-splits.lua` | ウィンドウ端での移動挙動（`at_edge = "stop"`） |
| `lua/plugins/neo-tree.lua` | ファイルツリーの設定（隠しファイル表示など） |
| `lua/lazy_setup.lua` | Leader キーの設定（Space） |
